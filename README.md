The line, in full:

> One hundred entries, one third place, thirty cents — and I'm already entering the next one.

## Run it

```sh
python3 main.py
```

`main.py` writes the line to `/output/entry.txt` (91 characters, one line, no trailing newline) and prints it. It self-checks the gate first: a single line of 1–100 characters, not blank. The run is fully deterministic — no input, no randomness, no network, no clock.
